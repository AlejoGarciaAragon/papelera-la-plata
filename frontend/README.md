# Vue 3 + JavaScript + Vite

This frontend uses Vue 3 with JavaScript and Vite. The components use Vue 3 `<script setup>` SFCs; check out the [script setup docs](https://vuejs.org/api/sfc-script-setup.html) to learn more.

Run `npm install` to install dependencies, `npm run dev` for development, and `npm run build` to generate the production bundle.
